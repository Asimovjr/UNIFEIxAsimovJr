# PRG Mobile

Aplicativo institucional desenvolvido pela Asimov Jr. para a PRG/UNIFEI.

## Requisitos

- Flutter 3.41.7
- Dart 3.11.5

## Rodando o projeto

flutter pub get
flutter run

## Qualidade

dart format .
flutter analyze
flutter test

## Workflow

1. Pegue uma task no Jira
2. Crie uma branch a partir da main
3. Desenvolva
4. Finalize a implementação
5. Solicite review
6. Merge após aprovação e CI

## Branches

prefix: feature/feature-name
